### 서버와 다른 점

| 항목 | `audiostackd` | 지금 서버 |
| --- | --- | --- |
| 세션 시작 | 데몬을 켜면 바로 세션을 만들어 `POST /api/sessions`. 끝낼 때까지 이어서 녹음 | 웹 버튼이 같은 경로를 호출하고, 서버가 본문을 무시한 채 세션을 만들어 mock STT를 켬 |
| 세션 번호 | 문자열 `sess-20261012-153001-4f2a` | `bigint`. 문자열이면 `400 INVALID_SESSION_ID` |
| 결과 전달 | `POST /api/sessions/{id}/transcripts` | 없는 경로 |
| 세션 종료 | `POST /api/sessions/{id}/end` | 없는 경로. 서버는 `/stop` |
| 녹음 전환 | `session rotate`는 지금 세션을 닫고 곧바로 새 세션을 염. 정지만 하는 명령은 없음 | 시작과 종료가 나뉘고, 녹음 안 하는 상태가 있음 |
| 세그먼트 번호 | 없음. `seq`는 partial과 final을 함께 세는 전달 번호 | `segmentId`가 필요하고 SSE `id`로도 씀 |
| 시각 | `t_start_ms`, `t_end_ms`는 선택 값이고 구간 기준 | `start_ms`, `end_ms`는 `not null`이고 세션 시작 기준 |
| 마지막 문장 | `session rotate`는 엔진에 `SESSION_END`를 보내고 곧바로 `/end`를 보냄. 결과에는 받은 시점의 세션 번호를 붙여, 늦게 온 final은 새 세션으로 감(`src/daemon.cpp`) | 정지 때 마지막 final을 기다리는 경로가 없음(C3) |
