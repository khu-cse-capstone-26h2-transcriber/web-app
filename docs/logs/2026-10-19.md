### 실패한 시도

- `npm install -D vite …`가 npm 10.8.2의 버그로 멈췄습니다. 위 표처럼 `--legacy-peer-deps`로 설치했습니다.
- 서버가 꺼졌을 때의 문구가 처음 의도와 달랐습니다(`HTTP 502`). 코드를 고쳐 다시 확인했습니다.
- 브라우저에서 메뉴를 누른 직후 화면 글자를 바로 읽으면 이전 화면이 읽혔습니다. React Router가 화면 전환을 transition으로 처리해 한 박자 늦기 때문이고, 잠시 기다린 뒤 다시 읽어 확인했습니다. 코드 문제는 아닙니다.
- 코드를 고친 직후 새로고침했을 때 한 번은 고치기 전 문구가 나왔습니다. Vite가 변경을 반영하는 중에 새로고침한 것이라 한 번 더 새로고침해 확인했습니다.

### 지침서 없이 구현하면서 정한 것

사용자가 정한 네 가지 밖에서 구현하며 정한 내용입니다. `docs/guides/T12.md`의 '결정 사항과 남은 질문'에 같은 내용이 있습니다.

- React Router는 7.x입니다. 8.x는 Node 22.22 이상이 필요합니다.
- Vite와 플러그인만 `--legacy-peer-deps`로 설치했고, `.npmrc`는 바꾸지 않았습니다.
- 화면 주소는 `/`(녹음), `/history`, `/history/:id`입니다.
- `/health`도 프록시로 넘기고, 미리보기 서버에도 같은 프록시를 둡니다.
- `vite.config.ts`는 루트 `.env`의 `PORT`를 읽고, 없으면 실패합니다.
- 타입 검사 설정을 브라우저 코드(`tsconfig.json`)와 `vite.config.ts`(`tsconfig.node.json`)로 나눴고, 루트 `typecheck`에 한 줄을 더했습니다.
- 데이터는 라우터 loader가 아니라 `useApiData` 훅으로 불러옵니다.
- 응답을 감싸는 타입(`Health`, `SessionDetail`)은 웹의 `endpoints.ts`에 둡니다.
- 프록시의 `502`는 `NETWORK_ERROR`로 봅니다.
- 서버 상태는 웹앱을 열 때 한 번만 확인합니다.
- 스타일은 `index.html`의 몇 줄과 헤더 인라인 스타일뿐입니다.
