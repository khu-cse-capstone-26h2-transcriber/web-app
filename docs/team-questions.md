**배경**

#### HW-2. 대기 상태와 녹음 시작·종료 명령 — T27 전 (답 받음)

**보낼 문장**

**배경**

- `--idle` 또는 `[session] autostart = false`로 켜면 대기 상태로 시작합니다. 저장소 기본값은 아직 `autostart = true`(켜자마자 녹음)입니다.

- 대기 중에 온 엔진 결과는 바로 앞 세션의 늦은 결과가 아니면 버립니다(`result while idle dropped`). 바로 앞 세션의 늦은 결과는 그 세션 번호로 보냅니다.

#### HW-3. 물리 버튼 — T27 전 (답 받음)

**보낼 문장**

**배경**

- 버튼이 `session rotate`를 부르면 녹음이 멈추지 않고 새 세션으로 넘어갑니다. 멈추려면 HW-2의 `session stop`이 필요합니다.

**앱 파트 제안**: 버튼은 데몬(또는 버튼 프로그램)이 읽고, 서버는 데몬의 세션 통지만 받습니다. 앱 서버가 GPIO를 직접 읽지는 않습니다.

**앱에서 할 일** (T27): XVF3800으로 바로 합니다. 1단계에서 우리 보드도 16 kHz 2채널로 잡히는지 보고, 같으면 `xvf3800-16k2ch.conf`를 그대로 씁니다. RNNoise는 이번에 켜지 않습니다(엔진 잡음 옵션 `NOISE=1`이 이미 켜져 있고, 따로 빌드해야 함). 켰을 때 인식률이 나아지는지는 나중에 비교합니다.
