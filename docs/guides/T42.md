2단계 빌드나 3단계 실행이 실패해 되돌린 경우는 **막힘**으로 기록하고, 오류와 박지윤께 물을 것을 남깁니다. 8단계나 9단계 시각 검사가 실패하면 완료가 아니라 **막힘**이고, PR #3을 보드에서 다시 봐야 합니다.
