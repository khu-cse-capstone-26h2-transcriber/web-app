# [T38] 디자인 기반 — 지침서

2026-11-19 · 이광호

## 목표

확정 디자인(2026-11-19, 시안 A + 왼쪽 사이드바, 어두운 테마)을 웹앱에 입히는 바탕을 만듭니다. 끝나면 아래가 됩니다.

1. 웹앱이 Tailwind CSS 4로 스타일을 쓰고, 확정안의 색 이름(bg, side, surface, surface2, text, muted, faint, rec, ok, warn 등)이 Tailwind 색 토큰으로 있습니다.
2. 글꼴은 Pretendard이고, 빌드에 들어가 인터넷 없이도 나옵니다.
3. 넓은 화면(768px 이상)에서는 왼쪽 사이드바(브랜드, 녹음·히스토리 메뉴, 최근 녹음 5개, 서버 상태)가 늘 보입니다.
4. 좁은 화면에서는 위쪽 막대(메뉴 버튼, 브랜드, 서버 상태)가 보이고, 메뉴 버튼으로 같은 사이드바를 서랍처럼 엽니다.

## 배경과 전제, 범위

- 2026-11-19 사용자 결정: 시안 A(라이브 자막형), 어두운 테마만, 왼쪽 사이드바, 웹 녹음 버튼은 작게, 날짜는 `formatStartedAt` 그대로, 기기·엔진 상태는 넣지 않고 서버 상태만. 구현은 Pretendard를 빌드에 넣고 Tailwind CSS를 씀.
- 확정안 7장(F-1~F-7)은 `exports/design-2026-11-19/`(git 제외)의 `final-a.html`과 `final-a-png/`에 있습니다. 색과 크기는 이 HTML의 값을 그대로 씁니다.
- 기기(Rubik Pi)가 인터넷 없이 웹앱을 내보낼 수 있으므로 글꼴 CDN을 쓰지 않습니다.
- 화면 안쪽(녹음 화면, 히스토리 화면)은 T39·T40에서 바꿉니다. 이 작업이 끝난 시점에는 화면 안쪽이 예전 모양(흰 배경용 색)으로 남습니다.

- 하는 것: 패키지 설치, Vite 설정, 전역 CSS와 색 토큰, 아이콘, 사이드바·위쪽 막대·서랍, 최근 녹음 목록, 서버 상태 표시 모양.
- 하지 않는 것: 사이드바의 '녹음 중' 표시(T39), 녹음·히스토리·404 화면 안쪽(T39·T40), 밝은 테마, 서버 API 변경, 단위 테스트(핵심 로직이 아님, CLAUDE.md 규칙).

## 구현 순서

1. `@app/web`에 `pretendard`(dependencies), `tailwindcss`·`@tailwindcss/vite`(devDependencies)를 설치합니다.
2. `vite.config.ts`에 `tailwindcss()`를 더하고, `index.css`에 `@import 'tailwindcss'`, `@theme` 색 토큰과 `--font-sans`, 기본 스타일(배경, 글자색, `word-break: keep-all`)을 씁니다.
3. `main.tsx`에서 Pretendard CSS와 `index.css`를 불러오고, `index.html`의 임시 스타일을 지웁니다.
4. `icons.tsx`에 마이크, 히스토리, 메뉴, 닫기, 화살표, 내려받기, 경고, 확인, 정지 아이콘과 브랜드 표시를 만듭니다.
5. `useRecentSessions`를 만들고, `Sidebar.tsx`에 브랜드·메뉴·최근 녹음·서버 상태를 그립니다.
6. `Layout.tsx`를 넓은 화면 사이드바, 좁은 화면 위쪽 막대와 서랍으로 바꿉니다. 화면 영역은 화면 높이를 채우고, 넘치면 화면 영역만 스크롤합니다.
7. 아래 '완료 기준'을 확인합니다.
8. 기록을 남깁니다(`project-overview.md`, 일지, 이 지침서 '결과'). `TODO.md`와 로컬 `CLAUDE.md`는 변경안을 먼저 보고합니다.
