# [T39] 녹음 화면 디자인 — 지침서

2026-11-19 · 이광호

## 목표

녹음 화면(`/`)과 사이드바의 녹음 표시를 확정안(F-1 녹음 중, F-2 대기, F-5 모바일 끊김 배너, F-7 요소와 상태)대로 바꿉니다. 끝나면 아래가 됩니다.

1. 녹음 중: 위쪽 상태 줄(빨간 `녹음 중` 알약, 큰 흐른 시간, `#48 · 2026-11-18 14:05 시작`, 작은 '녹음 종료' 버튼), 그 아래 화면 높이를 채우는 자막, 맨 아래 안내 문구와 `문장 N개`.
2. 자막은 최신 확정 문장이 가장 크고 밝으며, 지난 문장일수록 작고 흐립니다. 말하는 중인 문장(partial)은 최신 문장 크기로 흐리게, 끝에 빨간 커서가 붙습니다. 위로 스크롤해 읽는 동안에는 지난 문장이 모두 읽을 수 있는 색이 됩니다.
3. 대기: 가운데 점선 원 안의 마이크, `녹음하고 있지 않습니다`, 안내 두 줄, 작은 '녹음 시작' 버튼.
4. 끊김 배너는 노란 띠(경고 아이콘, 문구, '지금 다시 연결'), 회복 배너는 초록 띠입니다.
5. 사이드바 첫 메뉴가 녹음 중에는 빨간 점, `녹음 중`, 흐른 시간으로 바뀝니다. 녹음 화면이 아닌 곳(히스토리)에서도 그렇습니다.

## 배경과 전제, 범위

- 확정 디자인과 구현 방식은 T38 지침서의 '배경과 전제'와 같습니다. 화면의 동작(녹음 확인, 시작·종료, 끊김 처리, 이동)은 T13~T15, T20 그대로 두고 모양만 바꿉니다. 문구도 지금 문구를 씁니다(확정안 F-7이 지금 문구를 옮김).
- 지금은 녹음 화면만 진행 중인 녹음을 압니다(대기 중 2초마다 확인, T20). 사이드바가 다른 화면에서도 '녹음 중'을 보이려면 틀이 따로 알아야 합니다.

- 하는 것: 녹음 화면, 자막, 연결 배너, 사이드바 녹음 표시, 진행 중인 녹음 공유, 최근 녹음 다시 불러오는 시점.
- 하지 않는 것: 히스토리 화면과 404(T40), 녹음 화면 동작 변경, 서버 변경, 파형·음량 표시(서버가 오디오를 다루지 않음), 확장 기능(P2), 단위 테스트(핵심 로직이 아님).

## 구현 순서

1. `ElapsedTime`을 컴포넌트 파일로 옮깁니다.
2. `useActiveSessionPolling`을 만들고, `Layout`이 녹음 화면 밖에서 진행 중인 녹음을 갖고 있게 합니다. `LayoutContext`에 `activeSession`과 `reportActiveSession`을 더합니다. 최근 녹음은 진행 중이던 녹음이 끝나면 다시 불러옵니다.
3. 사이드바 첫 메뉴에 녹음 중 표시를 넣습니다.
4. `RecordPage`가 녹음 상태를 틀에 알리고, 화면을 확정안대로 바꿉니다(대기, 확인 중, 확인 실패, 녹음 중, 알림 문구, 아래 안내 줄).
5. `Transcript`에 자막 단계와 읽는 중 색을 넣고, 자막 영역이 남은 높이를 채우게 합니다. 자동 스크롤 규칙(T14)은 그대로입니다.
6. `ConnectionBanner`를 노란·초록 띠로 바꿉니다.
7. 아래 '완료 기준'을 확인합니다.
8. 기록을 남깁니다(`project-overview.md`, 일지, 이 지침서 '결과').
