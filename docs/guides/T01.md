# [T01] 모노레포 스캐폴딩 — 지침서

2026-10-10 · 이광호

원본: https://claude.ai/code/artifact/943636a2-b447-4e5b-ba2f-7dd3947703d0 (2026-10-10에 옮겨 적은 사본입니다. 내용이 다르면 원본이 최신입니다.)

## 목표

`npm install` 한 번으로 `apps/server`, `apps/web`, `packages/shared`가 연결된 모노레포가 만들어지고, `npm run typecheck`와 `npm run dev:server`가 통과합니다. 서버 콘솔에 shared 패키지 값이 찍히면 성공입니다.

## 배경과 전제, 범위

진행 보드의 확정된 결정에 따라 Node.js + TypeScript, npm workspaces 모노레포, React 웹앱, 주석·커밋은 한국어, 코드 식별자는 영어, Conventional Commits를 씁니다. 저장소는 D1 결정에 따라 **앱 전용 저장소를 새로 만들고**, 팀 저장소와의 연동 방식은 팀과 따로 합의합니다. 선행 작업은 없고, Node.js 20 이상과 git이 설치돼 있어야 합니다.

- 하는 것: 폴더 3개와 공통 TS 설정, `.env.example`, `.gitignore`, 로컬 git 저장소와 첫 커밋.
- 하지 않는 것: 원격 저장소 연결과 push(별도 진행), 서버 프레임워크 선택(D2, T04에서), 웹 빌드 도구 선택(D3, T12에서), DB와 docker(T02), 테스트 설정(T17).

## 폴더 구조와 파일

루트 폴더 이름은 `speech-transcriber`로 합니다(자유롭게 바꿔도 됩니다).

```text
speech-transcriber/
├─ package.json            # workspaces, 공통 스크립트(typecheck, dev:server)
├─ tsconfig.base.json      # 공통 컴파일러 옵션
├─ .gitignore              # node_modules, dist, .env
├─ CLAUDE.md               # Claude Code 작업 규칙(전달받은 파일)
├─ .env.example            # DB_URL, STT_URL, PORT 자리
├─ apps/
│  ├─ server/
│  │  ├─ package.json      # @app/server, shared 의존
│  │  ├─ tsconfig.json
│  │  └─ src/index.ts      # 임시 진입점(서버 프레임워크는 T04에서)
│  └─ web/
│     ├─ package.json      # @app/web, shared 의존
│     ├─ tsconfig.json
│     └─ src/index.ts      # 임시 진입점(React·빌드 도구는 T12에서)
└─ packages/
   └─ shared/
      ├─ package.json      # @app/shared, main: src/index.ts
      ├─ tsconfig.json
      └─ src/index.ts      # APP_NAME 상수 하나만 내보냄
```

## 구현 순서

1. 폴더와 git 저장소를 만듭니다.

    ```bash
    mkdir -p speech-transcriber/{apps/server/src,apps/web/src,packages/shared/src}
    cd speech-transcriber
    git init -b main
    ```

2. `package.json`(루트)를 만들고 개발 도구를 설치합니다.

    ```json
    {
      "name": "speech-transcriber",
      "private": true,
      "type": "module",
      "workspaces": ["apps/*", "packages/*"],
      "scripts": {
        "typecheck": "tsc --noEmit -p apps/server && tsc --noEmit -p apps/web && tsc --noEmit -p packages/shared",
        "dev:server": "npm run dev -w @app/server"
      }
    }
    ```

    ```bash
    npm install -D typescript tsx @types/node
    ```

3. `tsconfig.base.json`(루트)에 공통 옵션을 씁니다.

    ```json
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ESNext",
        "moduleResolution": "Bundler",
        "strict": true,
        "esModuleInterop": true,
        "skipLibCheck": true,
        "noEmit": true
      }
    }
    ```

4. 세 패키지의 `package.json`과 `tsconfig.json`을 만듭니다. 패키지 이름은 `@app/shared`, `@app/server`, `@app/web`입니다.

    - `packages/shared/package.json`: `{ "name": "@app/shared", "version": "0.0.0", "type": "module", "main": "src/index.ts" }`
    - `apps/server/package.json`: `{ "name": "@app/server", "version": "0.0.0", "type": "module", "scripts": { "dev": "tsx src/index.ts" }, "dependencies": { "@app/shared": "*" } }`
    - `apps/web/package.json`: `@app/server`와 같은 형태에 이름만 `@app/web`이고 `scripts`는 없습니다.
    - 각 `tsconfig.json`: `{ "extends": "../../tsconfig.base.json", "include": ["src"] }` (`packages/shared`도 경로는 같습니다).

5. 소스 파일 3개를 씁니다.

    ```ts
    // packages/shared/src/index.ts
    export const APP_NAME = 'speech-transcriber';
    ```

    ```ts
    // apps/server/src/index.ts
    import { APP_NAME } from '@app/shared';
    console.log(`[server] ready - ${APP_NAME}`);
    ```

    ```ts
    // apps/web/src/index.ts
    import { APP_NAME } from '@app/shared';
    export const title = APP_NAME;
    ```

6. `.env.example`과 `.gitignore`를 만듭니다.

    ```bash
    # .env.example
    PORT=3000
    DB_URL=postgres://user:password@localhost:5432/transcriber
    STT_URL=http://localhost:9000
    ```

    `.gitignore`에는 `node_modules/`, `dist/`, `.env` 세 줄을 씁니다.

7. 전달받은 `CLAUDE.md`를 루트에 복사한 뒤, 설치하고 동작을 확인하고 커밋합니다.

    ```bash
    npm install
    npm run typecheck
    npm run dev:server
    git add -A
    git commit -m "chore: 모노레포 스캐폴딩"
    ```

## 완료 기준

| 명령어 | 기대 출력 |
| --- | --- |
| `npm install` | 에러 없이 끝남, `ls -l node_modules/@app`에 `shared`, `server`, `web` 심볼릭 링크 3개 |
| `npm run typecheck` | 출력 없이 종료 코드 0 |
| `npm run dev:server` | `[server] ready - speech-transcriber` 출력 후 종료 |
| `git check-ignore .env` | `.env` 출력(비밀 파일이 커밋에 포함되지 않음) |
| `git log --oneline` | `chore: 모노레포 스캐폴딩` 커밋 1개 |
